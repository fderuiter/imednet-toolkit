# Cross-Harness Agent Skills & Governance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Unify `.agents/skills/` (`52 -> 31` canonical skills), `AGENTS.md`, `docs/agents/*`, `.gitignore`, and CI/harness tooling (`scripts/ci_plan.py`, `scripts/check_root_files.py`, `scripts/setup_agent_harnesses.py`) into a Python-tailored, cross-harness engineering suite working identically on ChatGPT/Codex, Claude Code, and Google Antigravity.

**Architecture:** Isolate all harness-specific dialect translations (`using-superpowers/references/{antigravity,claude-code,codex}-tools.md`, `agents/openai.yaml`, and gitignored local `.claude/` + `CLAUDE.md` bridges generated by `scripts/setup_agent_harnesses.py`) behind one action-only `SKILL.md` interface, collapse shallow/alien skills, merge the five competing workflow pairs, sync governance docs with live GitHub labels, and guard invariants with deterministic pytest contract tests plus targeted behavioral subagent checks.

**Tech Stack:** Python >=3.11, `pytest`, `PyYAML`, `uv`, `hatch`, `ruff`, `mypy`, `typos`, `pre-commit`, Sphinx (`scripts/build_docs.py`), GitHub CLI (`gh`), OpenAI Codex / Claude Code / Google Antigravity Agent Skills (`SKILL.md` + `agents/openai.yaml`).

**Spec:** [2026-11-16-cross-harness-skills-synergy-design.md](../specs/2026-11-16-cross-harness-skills-synergy-design.md)

## Global Constraints

- Exactly **31** skill directories remain in `.agents/skills/`, registered via `.agents/skills.json` and documented in `.agents/skills/README.md`.
- Every skill uses harness-neutral action vocabulary in `SKILL.md` (zero `Skill tool`, `TodoWrite`, `write_to_file`, `replace_file_content`, `ArtifactType`, `claude --bg` leaks in `SKILL.md`), follows `agentskills.io` frontmatter (`name` matches directory name, concise `description`), and pairs `disable-model-invocation: true` **1:1** with `policy.allow_implicit_invocation: false` in `agents/openai.yaml`.
- Root `AGENTS.md` stays `<10 KB` (under Antigravity's `24,000`-byte cap and Codex's `32 KiB` cap).
- Zero tracked git symlinks (`git config core.symlinks` is `false` on Windows); Claude Code bridging is strictly local and gitignored via `.claude/` and `CLAUDE.md`.
- `docs/agents/triage-labels.md` holds explicit precedence over stale label names in frozen `docs/reference/{issue_management,triage_playbook}.rst` and `.github/ISSUE_TEMPLATE/*.yml`.
- `triage` uses GitHub-native `wontfix` memory (`gh issue list --label wontfix --state closed` + structured closing comments); `triage/OUT-OF-SCOPE.md` and `.out-of-scope/` are removed/not used.
- Every `.py` file under `scripts/` and `tests/` satisfies `ruff` (`select = ["PL", "PIE", "FURB", "E", "F", "I", "N", "SLF", "D", "S", "B", "C4", "SIM", "UP", "PT", "RET", "RUF"]` with Google docstrings per `pyproject.toml`), `typos`, LF line endings, and zero trailing whitespace.
- Verification gates before PR creation: `uvx pre-commit run --all-files`, `hatch run verify` (`>=90%` coverage), `hatch run docs`, targeted behavioral subagent runs on the 6 high-risk discipline/merged skills, and `uvx hatch run quality:all packages` (where applicable).

- **Existing non-bridge `.claude/skills` directory collision on Windows/POSIX:** `scripts/setup_agent_harnesses.py` must fail clearly without overwriting or deleting an existing regular directory containing user files at `.claude/skills`, while remaining idempotent when an expected junction/symlink already points to `.agents/skills` → pinned in `tests/unit/test_setup_agent_harnesses.py`.
- **Unquoted or backslash paths in `ci_plan.py` ignores:** Changed file inputs on Windows or CI carrying `./.agents/...` or `.agents\skills\...\openai.yaml` must normalize cleanly and return `{"test": [], "build": []}` instead of triggering 4-package fallback builds, while `scripts/setup_agent_harnesses.py` edits still trigger CI → pinned in `tests/unit/test_ci_plan.py`.
